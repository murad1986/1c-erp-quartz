# week-pipeline — Полный пайплайн создания недели

**Аргумент:** `<week>` (например: `3`)

Запускает все 5 шагов создания недели последовательно с подтверждением между шагами.

---

## ШАГ 1/5 — НАПИСАНИЕ УРОКОВ

Напиши все 7 уроков Week $ARGUMENTS, последовательно применяя правила из `write-lesson`:

Для каждого дня (1 → 7):
1. Прочитай `lesson_writer_agent.md`
2. Проверь `promise_registry.md` и `case_registry.md`
3. Прочитай предыдущий урок для контекста
4. Напиши урок в `week_$WEEK/day_N.md`
5. Обнови реестры

После написания всех 7 уроков выведи:

```
✅ ШАГ 1/5 ЗАВЕРШЁН — написано 7 уроков для Week N

Краткий список:
- Day 1: <название> (концепты: X, Y, Z)
- Day 2: <название> (концепты: ...)
- ...
- Day 7: <название> (лонгрид)

Продолжить к Шагу 2 (ревью)? Напиши "да" или укажи правки.
```

---

## ШАГ 2/5 — РЕВЬЮ УРОКОВ

Применяй правила из `review-week` для Week $ARGUMENTS:
- Прочитай все 7 уроков
- Проверь каждый по чеклисту
- Выведи структурированный отчёт

После вывода отчёта:

```
✅ ШАГ 2/5 ЗАВЕРШЁН — ревью Week N

Найдено проблем: N
Уроков с проблемами: [Day X, Day Y]

Продолжить к Шагу 3 (исправление)? Напиши "да" или пропусти шаг.
```

---

## ШАГ 3/5 — ИСПРАВЛЕНИЕ

Применяй правила из `fix-lesson` для каждого урока с проблемами из Шага 2:
- Читай каждый проблемный урок
- Применяй только найденные исправления
- Сохраняй файлы

После завершения:

```
✅ ШАГ 3/5 ЗАВЕРШЁН — исправлено N уроков

- Day X: N исправлений
- Day Y: M исправлений

Продолжить к Шагу 4 (генерация иллюстраций)?
```

---

## ШАГ 4/5 — ГЕНЕРАЦИЯ ПРОМПТОВ ИЛЛЮСТРАЦИЙ

Применяй правила из `illustrations-gen` для Week $ARGUMENTS:
- Прочитай `visual_prompts.md`
- Прочитай все 7 уроков
- Создай `week_$WEEK_illustration_prompts.md`

После завершения:

```
✅ ШАГ 4/5 ЗАВЕРШЁН — создан week_N_illustration_prompts.md

Иллюстраций запланировано: N
- Day 1: N иллюстраций
- Day 2: M иллюстраций
- ...

Продолжить к Шагу 5 (встройка в уроки)?
```

---

## ШАГ 5/5 — ВСТРОЙКА ПРОМПТОВ

Применяй правила из `illustrations-embed` для Week $ARGUMENTS:
- Прочитай `week_$WEEK_illustration_prompts.md`
- Встрой `<!--illustration-->` блоки в каждый урок

После завершения:

```
🎉 ШАГ 5/5 ЗАВЕРШЁН — пайплайн Week N завершён!

Встроено иллюстраций: N
Изменено файлов: 7

Следующие шаги:
- Запусти sync-content скрипт чтобы обновить сайт
- Сгенерируй иллюстрации в Nano Banana из week_N_illustration_prompts.md
- Разложи PNG в course_site/public/lesson-assets/week_N/day_N/
```
