# illustrations-gen — Генерация промптов иллюстраций

**Аргумент:** `<week>` (например: `3`)

Создай файл `week_$ARGUMENTS_illustration_prompts.md` с промптами для всех иллюстраций недели.

## Шаги

1. **Прочитай визуальный стиль** — `visual_prompts.md`
   - §1: STYLE BLOCK (вставлять в конец каждого промпта)
   - §2: Принцип визуализации
   - §3: Типы иллюстраций (Structural, Process, Comparative, Traps, Summary)
   - §4: Формат блока в уроке

2. **Прочитай образец** — `week_1_illustration_prompts.md` (пример формата файла)

3. **Прочитай все 7 уроков** недели:
   `week_$WEEK/day_1.md` … `week_$WEEK/day_7.md`

4. **Для каждого урока** определи 3-5 иллюстраций:
   - Выбирай типы из §3 `visual_prompts.md`, подходящие к содержимому
   - **Обязательно:** `skill_tree` (тип Summary) для каждого из Days 1-5
   - Выбирай моменты, где визуал действительно помогает: структуры данных, сравнения, ошибки, пайплайны
   - Day 6 и Day 7: 1-2 иллюстрации максимум

5. **Напиши промпты**:
   - Каждый промпт: конкретное описание содержимого (данные из урока, подписи, элементы)
   - Используй реальные примеры из урока — конкретные имена переменных, значения, код
   - Весь текст в иллюстрациях — на русском
   - Добавь `[STYLE BLOCK]` из `visual_prompts.md §1` в конец каждого промпта

6. **Создай/перезапиши файл** `week_$WEEK_illustration_prompts.md`

```markdown
# Промпты для иллюстраций — Неделя N

> **Вставка:** блоки <!--illustration--> в файлах уроков
> **Генератор:** Nano Banana (Gemini)
```
