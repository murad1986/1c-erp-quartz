# write-lesson — Написание урока

**Аргументы:** `<week> <day>` (например: `3 1`)

Напиши урок для Week $ARGUMENTS (формат: первое число — неделя, второе — день).

## Шаги

1. **Прочитай правила** — `lesson_writer_agent.md` (главный свод правил написания уроков)

2. **Проверь реестр обещаний** — `promise_registry.md`
   - Найди обещания для текущей недели
   - Убедись, что урок выполняет нужные обещания из предыдущих дней

3. **Проверь реестр кейсов** — `case_registry.md`
   - Не повторяй уже использованные примеры и кейсы
   - Выбери новые примеры в игровой тематике

4. **Прочитай предыдущий урок** для контекста — `week_N/day_M.md` (день - 1)
   - Если это Day 1, прочитай последний урок предыдущей недели

5. **Напиши урок** со структурой по `lesson_writer_agent.md`:
   - YAML front matter (title, week, day, concepts)
   - Вступление с игровой аналогией
   - Части 1-N (не более 3-4 новых концептов)
   - Задания (включая мини-проект)
   - `<quiz>` блоки
   - Навигация (← предыдущий | следующий →)

6. **Обнови реестры**:
   - `promise_registry.md` — отметь выполненные обещания, добавь новые
   - `case_registry.md` — добавь использованные в этом уроке кейсы

## Ограничения

- Не более 3-4 новых концептов на урок
- Без `lambda`, `import`, list comprehension до Week 5
- Все code blocks: запускаемые, с комментарием-выводом, ≤ 20 строк
- Day 6 — только практика, никакого нового материала
- Day 7 — лонгрид, никакого нового кода

## Путь файла

Сохрани в `week_$WEEK/day_$DAY.md`
