# illustrations-embed — Встройка промптов в уроки

**Аргумент:** `<week>` (например: `3`)

Встрой `<!--illustration-->` блоки из `week_N_illustration_prompts.md` в файлы уроков.

## Шаги

1. **Прочитай формат блока** — `visual_prompts.md §4`

2. **Прочитай промпты** — `week_$ARGUMENTS_illustration_prompts.md`
   - Зафиксируй для каждой иллюстрации: файл, тип, где в уроке, промпт

3. **Для каждой иллюстрации**:
   a. Открой соответствующий файл урока `week_$WEEK/day_N.md`
   b. Найди нужное место (по описанию "Где в уроке" из промпт-файла)
   c. Вставь блок строго по формату (см. ниже)

4. **Конвертируй существующие** `![alt](path)` → `<!--illustration-->` блоки
   если они относятся к той же неделе

5. **Сохрани** каждый изменённый файл

## Строгий формат блока

```
<!--illustration
file: day_N/filename.png
alt: Описание на русском
prompt:
[Содержимое промпта]

[STYLE BLOCK]
-->
```

Блок вставляется **сразу после абзаца**, к которому относится (не до, не через строку).

Пустая строка перед блоком и пустая строка после блока.

## Формат ответа

```
## Встроено: Week N

- day_1.md: 3 иллюстрации добавлены (строки 12, 45, 78)
- day_2.md: 4 иллюстрации добавлены (строки 8, 31, 55, 89)
- day_3.md: 3 иллюстрации добавлены
- ...

Всего блоков добавлено: N
```
