# review-week — Ревью уроков недели

**Аргумент:** `<week>` (например: `3`)

Проведи ревью всех 7 уроков Week $ARGUMENTS по критериям из `lesson_writer_agent.md`.

## Шаги

1. Прочитай `lesson_writer_agent.md` — критерии качества
2. Прочитай все 7 файлов: `week_$WEEK/day_1.md` … `week_$WEEK/day_7.md`
3. Для каждого урока проверь по чеклисту ниже

## Чеклист проверки

### Структура и объём
- [ ] Новых концептов ≤ 4
- [ ] Есть мини-проект (Задание 4 или последнее задание)
- [ ] Есть навигация (← / →)

### Code blocks
- [ ] Все примеры запускаемые (нет обрывков, нет псевдокода без пометки)
- [ ] Каждый блок показывает вывод (в комментарии или сразу после)
- [ ] Длина блока ≤ 20 строк

### Интерактивность
- [ ] Есть `<quiz>` блоки (минимум 1 на урок)
- [ ] Есть элементы `<details>/<summary>` для подсказок или дополнений

### Специфика дней
- [ ] Day 6 — ТОЛЬКО практика, нет объяснений нового материала
- [ ] Day 7 — лонгрид, нет новых code-заданий, есть размышление/история

### Анти-паттерны (каждый = проблема)
- [ ] Нет голых таблиц без контекста
- [ ] Нет терминов без объяснения через аналогию
- [ ] Нет `lambda`/`import`/list comprehension (если неделя < 5)
- [ ] Нет абзацев "стены текста" > 5 строк без примера

## Формат вывода

```
## Ревью Week N

### [Day 1] — <Название урока>
✅ Концептов: 3 — OK
✅ Мини-проект: есть
⚠️ [CODE] Блок на строке 47 не показывает вывод → добавить комментарий с результатом
⚠️ [QUIZ] Отсутствует quiz блок → добавить 1-2 вопроса

### [Day 2] — <Название урока>
✅ Всё OK

...

## Итого
- Проблем найдено: N
- Уроков без проблем: M
- Требуют исправления: [Day X, Day Y]
```

Используй `✅` для норм, `⚠️` для предупреждений, `❌` для критических проблем.
