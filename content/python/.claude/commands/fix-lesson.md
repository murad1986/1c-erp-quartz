# fix-lesson — Исправление урока

**Аргументы:** `<week> <day>` или `<week> all`

Примеры:
- `3 2` — исправить Day 2 недели 3
- `3 all` — исправить все уроки недели 3

## Шаги

1. **Прочитай файл урока** — `week_$WEEK/day_$DAY.md`

2. **Прочитай правила** — `lesson_writer_agent.md`
   - Освежи в памяти критерии, на которые жаловалось ревью

3. **Примени исправления**:
   - Если пользователь указал конкретные проблемы — исправь только их
   - Если пользователь написал `all` — применяй стандартный чеклист из review-week
   - **Не трогай то, что не сломано** — только указанные исправления

4. **Сохрани файл** с исправлениями

## Принципы исправления

- Минимальные изменения — только то, что нужно
- Не переписывай стиль, тон и структуру, если они не нарушены
- Если исправление требует добавить quiz — добавь в конец нужного раздела
- Если нужно сократить code block — убери избыточные строки, сохрани суть
- Если нужно добавить вывод — добавь как комментарий `# → результат`

## Формат ответа

После применения исправлений выведи:

```
## Исправлено: Week N, Day M

- [строка XX] Добавлен вывод в code block
- [раздел "Часть 3"] Добавлен <quiz> блок
- [строка YY] Разбит абзац-стена на два

Всего изменений: N
```
