## Обязательная часть — финальная сборка

### Задание 1 — Полная структура проекта

Убедись, что квест разбит на модули (Day 2) и работает через `python main.py`:

```
quest/
├── main.py
├── models.py
├── world.py
├── commands.py
├── save.py
├── loot.py
├── exceptions.py
└── save.json  (появится после первого сохранения)
```

Все команды работают без ошибок:
```
смотреть | карта | статус | помощь | выход
идти [направление]
взять / бросить / инвентарь / осмотреть [предмет]
атаковать [враг]
использовать [предмет]
сохранить
```

<details>
<summary>Бонус 1 — Уникальный сюжет</summary>

Напиши **5 строк лора** — кто такой Некромант, почему ты здесь, что случилось с катакомбами. Добавь это в описания комнат и NPC-записки (Item с описанием страницы из дневника).

Пример:
```python
note = Item(
    "Страница дневника",
    "«День 47. Некромант запечатал выход. Ключ — в темнице. "
    "Не могу добраться. Если кто найдёт это — беги.»"
)
```
</details>
